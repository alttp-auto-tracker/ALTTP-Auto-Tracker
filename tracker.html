Streamer URLs

This builds a URL to streamer.html — a dedicated overlay layout (timer on top, items left, map right, transparent center for your game capture). Use one OBS Browser Source. SNI only allows a single device attach, so disconnect the main tracker first or the overlay will sit idle.

Host should be reachable from the OBS machine (localhost if SNI runs on the same PC). Serve the folder with start-tracker-windows.bat (or python -m http.server 8000) — do not use a file:// path in OBS.

Experimental. Stream overlay layouts and slot presets are still evolving. Expect occasional layout quirks; report issues and prefer Classic or Race for production streams.
